## 한 줄 소개

쇼핑몰 주소 하나로 AI와 고객에게 제공할 기본 정보를 점검하고, 무엇부터 고치면 좋을지 알려주는 서비스입니다.

## 서비스 링크

https://alswhitetiger.github.io/ai-visibility-check/

## 해결하려는 문제

쇼핑몰 운영자는 페이지에 어떤 정보가 빠졌는지 알아도, 개발 용어가 어렵고 수정 위치를 몰라 실행으로 옮기기 어렵습니다. 이 서비스는 접근 규칙·브랜드 데이터·페이지 소개 등을 점검한 뒤, 어려운 기술 용어 대신 질문과 수정 안내를 먼저 보여줍니다.

제출 화면용 100자 이내 문구: `쇼핑몰 운영자가 AI와 고객에게 필요한 정보를 찾고 직접 고칠 수 있도록 공개 페이지를 점검하고 실행 가능한 수정 안내를 제공합니다.`

## 사용 흐름

주소 입력 → 기본 정보 점검 → 먼저 고칠 3가지와 코드 예시 → 운영자가 직접 수정 → 다시 검사하고 전후 항목 비교.

가상의 쇼핑몰 예시와 실제 공개 페이지 검사를 로그인 없이 체험할 수 있습니다. 익명 검사는 하루 1회이며, 이메일 또는 Google·카카오·네이버 로그인 뒤에는 사이트 저장, 검사 이력과 공유 보고서를 이용할 수 있습니다. 가상 예시는 화면에 명확하게 표시하며 실제 고객 사례로 제시하지 않습니다.

## AI 활용 방식

검증 가능한 페이지 설정은 HTML·robots.txt 파싱으로 확인합니다. LLM은 Gemini만 사용하며, 브랜드명과 도메인을 알려주는 설명 질의와 이를 전혀 알려주지 않는 소비자 질문을 분리합니다. 저장된 브랜드 설명 응답이 있으면 수집일과 함께 재사용합니다.

이 응답에는 웹 검색을 사용하지 않습니다. 특정 API 모델의 답변이며 소비자 서비스의 실제 검색 노출이나 추천 순위와 같지 않습니다. AI 응답은 기본 정보 점수와 분리해 표시합니다.

주요 AI 도구: Gemini API(서비스 기능), Claude Code·Codex(개발 보조). 실행 시 실제 응답을 제공한 모델은 리포트에서 확인할 수 있습니다.

제출 화면용 AI 활용 방식(500자 이내):

> 쇼핑몰의 공개 HTML과 robots.txt를 규칙 기반으로 점검해 AI 정보와 고객 정보의 준비 상태를 2축 점수로 보여줍니다. Gemini API는 페이지에서 읽은 제한된 근거로 소개 문구·고객 질문·FAQ 초안을 만들고, 브랜드명과 주소를 알려주지 않은 소비자 질문으로 가게가 모델 지식에 등장하는지도 확인합니다. 답변은 모델·근거와 함께 표시하며 운영자가 사실을 확인한 뒤 적용하도록 합니다. 로그인 회원은 검사 이력, 사이트맵 핵심 페이지 묶음 검사, 전후 비교 공유와 PDF 저장을 이용합니다. 실제 검색 순위나 매출을 보장하지 않습니다.

## 구현과 검증

- React + Vite / GitHub Pages, Cloudflare Worker + D1
- 입력한 페이지 및 기본 안내 파일 조회, 홈페이지와 상품 페이지의 검사 범위 분리
- 조직·상품 데이터 및 실제 가격 필드 확인, HTML 오류 페이지와 파일 형식 구분
- URL 경로별 robots 규칙 적용, 접근 규칙 조회 실패 시 검사 중단
- 검사 버전별 캐시 검증, 일일 사용량 제한, API 없이 열리는 예시
- 코드 예시 복사, 재검사와 같은 브라우저의 전후 비교, 원본 근거 링크
- 고객 질문 검사, 운영자 인터뷰 답변을 이용한 소개·FAQ·FAQ 구조화 데이터 초안
- 사이트맵 기반 핵심 페이지 자동 추천, 2~5개 묶음 검사와 검사 이력 두 시점 비교
- 전후 비교 보고서의 30일 읽기 전용 링크와 PDF 출력
- 브랜드명·주소를 모델에 알려주지 않는 소비자 질문 기반 Gemini 기억 검사
- 이메일 인증과 Google·카카오·네이버 로그인, 사이트·이력 저장과 공유 보고서
- 단위·회귀 테스트와 데스크톱·모바일 브라우저 검증

## 심사 시 체험 방법

1. 첫 화면의 ‘주소 없이 예시 먼저 보기’를 누릅니다.
2. ‘먼저 고칠 부분’에서 검사 근거와 코드 예시를 펼칩니다.
3. ‘수정 후 예시와 비교하기’로 달라진 3개 항목을 확인합니다.
4. 실제 쇼핑몰 또는 상품 URL을 넣어 익명 검사를 실행합니다. 결과에서 고객 질문을 확인하고 운영자 답변으로 소개·FAQ 초안을 만듭니다.
5. 로그인하면 사이트맵에서 핵심 페이지를 추천받고, 검사 이력 두 건의 전후 비교·공유 링크·PDF 출력을 이용할 수 있습니다.

실시간 검사가 제한되더라도 가상 예시는 계속 열 수 있습니다. 실제 사이트의 설정은 자동으로 변경하지 않습니다.

## 한계와 확장 방향

현재 점수는 자체 기준의 기본 정보 준비 상태입니다. 실제 AI 추천·검색 노출·구매 성공률을 보장하지 않습니다. 브랜드 비노출 검사는 사용자가 입력한 한 질문에 대한 Gemini의 모델 지식 응답이며 실시간 검색 순위나 전체 소비자 질문을 대표하지 않습니다. 다음 검증 과제는 동의한 운영자가 수정 안내를 따라 완료할 수 있는지 관찰하는 것입니다.
