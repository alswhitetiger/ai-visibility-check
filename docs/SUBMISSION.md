# 제출 문구 · 원티드 AI Championship 2026

업데이트: 2026-09-10. 현재 구현 범위 기준입니다. 이전 조사 수치를 효과 검증이나 시장 전체의 통계로 사용하지 않습니다.

## 서비스명

가게 체크 · AI Visibility Check

## 한 줄 소개

쇼핑몰 주소 하나로 AI와 고객에게 제공할 기본 정보를 점검하고, 무엇부터 고치면 좋을지 알려주는 서비스입니다.

## 서비스 링크

https://alswhitetiger.github.io/ai-visibility-check/

## 해결하려는 문제

쇼핑몰 운영자는 페이지에 어떤 정보가 빠졌는지 알아도, 개발 용어가 어렵고 수정 위치를 몰라 실행으로 옮기기 어렵습니다. 이 서비스는 접근 규칙·브랜드 데이터·페이지 소개 등을 점검한 뒤, 어려운 기술 용어 대신 질문과 수정 안내를 먼저 보여줍니다.

## 사용 흐름

주소 입력 → 기본 정보 점검 → 먼저 고칠 3가지와 코드 예시 → 운영자가 직접 수정 → 다시 검사하고 전후 항목 비교.

가상의 쇼핑몰을 이용한 전체 예시는 로그인 없이 바로 체험할 수 있습니다. 실제 쇼핑몰 주소를 검사하려면 무료 회원가입(이메일)이 필요합니다. 가상 예시는 화면에 명확하게 표시하며 실제 고객 사례로 제시하지 않습니다.

## AI 활용 방식

검증 가능한 페이지 설정은 HTML·robots.txt 파싱으로 확인합니다. LLM은 브랜드명과 도메인을 알려주고 브랜드 설명을 질의하는 데 사용합니다. 설정된 키에 따라 Gemini → OpenAI → Anthropic 순서로 시도하며 저장된 응답이 있으면 수집일과 함께 재사용합니다.

이 응답에는 웹 검색을 사용하지 않습니다. 특정 API 모델의 답변이며 소비자 서비스의 실제 검색 노출이나 추천 순위와 같지 않습니다. AI 응답은 기본 정보 점수와 분리해 표시합니다.

개발 도구: Claude Code, Codex. 실행 시 실제 응답을 제공한 모델은 리포트에서 확인할 수 있습니다.

## 구현과 검증

- React + Vite / GitHub Pages, Cloudflare Worker + D1
- 입력한 페이지 및 기본 안내 파일 조회, 홈페이지와 상품 페이지의 검사 범위 분리
- 조직·상품 데이터 및 실제 가격 필드 확인, HTML 오류 페이지와 파일 형식 구분
- URL 경로별 robots 규칙 적용, 접근 규칙 조회 실패 시 검사 중단
- 검사 버전별 캐시 검증, 일일 사용량 제한, API 없이 열리는 예시
- 코드 예시 복사, 재검사와 같은 브라우저의 전후 비교, 원본 근거 링크
- 단위·회귀 테스트와 데스크톱·모바일 브라우저 검증

## 심사 시 체험 방법

1. 첫 화면의 ‘주소 없이 예시 먼저 보기’를 누릅니다.
2. ‘먼저 고칠 부분’에서 검사 근거와 코드 예시를 펼칩니다.
3. ‘수정 후 예시와 비교하기’로 달라진 3개 항목을 확인합니다.
4. 실제 쇼핑몰 또는 상품 URL을 넣어 검사합니다. 로그인이 필요하다는 안내가 뜨면 '로그인하고 검사하기'로 무료 가입 후 공개 페이지를 검사합니다.

실시간 검사가 제한되더라도 가상 예시는 계속 열 수 있습니다. 실제 사이트의 설정은 자동으로 변경하지 않습니다.

## 한계와 확장 방향

현재 점수는 자체 기준의 기본 정보 준비 상태입니다. 실제 AI 추천·검색 노출·구매 성공률을 보장하지 않습니다. 다음 검증 과제는 동의한 운영자가 수정 안내를 따라 완료할 수 있는지 관찰하는 것입니다. 이후 검색을 사용하는 브랜드 비노출 질문 실험과 인용 근거 수집을 별도 측정으로 확장할 수 있습니다. 해당 기능과 사용자 검증 결과는 현재 구현 또는 완료된 성과로 주장하지 않습니다.
