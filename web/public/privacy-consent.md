# 가게 체크 개인정보 수집·이용 동의서

- 시행일: 2026년 9월 14일
- 적용 대상: 가게 체크 이메일 회원가입 및 회원 기능

## 1. 필수 개인정보 수집·이용

| 구분 | 내용 |
|---|---|
| 수집·이용 목적 | 계정 생성과 로그인, 이메일 소유 확인, 비밀번호 재설정, 부정 이용 방지, 계정 보안, 회원 전용 사이트·검사 기록 제공 |
| 회원이 입력하는 필수 항목 | 이름 또는 닉네임, 이메일 주소, 비밀번호 |
| 서버에 저장되는 형태 | 이름 또는 닉네임, 이메일 주소, 비밀번호 해시, 이메일 인증 여부, 가입·수정 시각 |
| 자동 생성 정보 | 세션 토큰, 로그인 시각, IP 주소, 브라우저·기기 정보(User-Agent) |
| 보유·이용 기간 | 회원 정보는 회원 탈퇴 또는 삭제 요청 처리 시까지, 로그인 세션은 최대 7일 또는 로그아웃 시까지. 관계 법령에 따라 보존할 의무가 생기면 해당 기간 동안 분리 보관할 수 있음 |

비밀번호 원문은 저장하지 않습니다. 비밀번호는 인증 라이브러리의 scrypt 방식으로 해시해 저장합니다.

## 2. 이메일 인증번호

- 회원가입을 제출하면 입력한 이메일 주소로 6자리 인증번호를 발송합니다.
- 인증번호의 유효 시간은 발급 시점부터 10분입니다.
- DB에는 인증번호 원문 대신 해시와 실패 횟수를 저장합니다.
- 5회 잘못 입력하면 해당 번호를 더 이상 사용할 수 없습니다.
- 인증에 성공하거나, 만료된 번호를 확인하거나, 번호를 재발급하면 기존 인증 값은 삭제되거나 새 값으로 교체됩니다.
- 인증 메일은 운영자의 Gmail SMTP를 통해 발송되며, 이메일 발송을 위해 수신 이메일 주소·인증번호·발송 내용이 Google의 메일 서버로 전달됩니다.

## 3. 회원 기능을 이용할 때 추가로 저장되는 정보

| 기능 | 저장 항목 | 이용 목적 및 기간 |
|---|---|---|
| 내 사이트 | 사이트 주소, 사용자가 정한 표시 이름, 등록 시각 | 반복 검사 편의 제공. 사용자가 삭제하거나 회원 정보 삭제 요청을 처리할 때까지 |
| 검사 이력 | 사이트 주소, 검사 결과, 검사 시각 | 결과 비교와 개선 추적. 최근 90일 범위를 제공하며 사용자가 먼저 삭제할 수 있음 |
| 검사 이용량 | 회원 식별자, 이용 날짜, 처리 상태와 시각 | 일일 한도 적용과 중복 차감 방지 |
| 공유 보고서 | 무작위 공유 토큰, 단일 검사 결과 또는 사용자가 선택한 두 검사 결과, 만료 시각 | 단일 결과나 전후 비교를 링크로 공유. 링크는 생성 후 30일 동안만 조회 가능 |

회원은 계정 화면에서 직접 탈퇴할 수 있습니다. 탈퇴가 완료되면 계정, 연결된 로그인, 세션, 내 사이트, 검사 이력, 검사 이용량, 개선 체크리스트와 공유 보고서를 영구 삭제합니다. 여러 사용자의 동일한 공개 페이지 요청을 줄이기 위해 주소별로 저장된 공용 진단 캐시는 개인 계정 자료가 아니므로 회원 탈퇴 대상에 포함되지 않습니다.

검사 대상은 인터넷에 공개된 페이지여야 합니다. 사이트 주소에 이메일 주소, 주문번호, 로그인 토큰과 같은 개인정보나 비밀 값을 넣지 마세요. 공개 페이지의 검사 결과는 외부 AI 호출과 중복 수집을 줄이기 위해 공용 캐시로 재사용될 수 있습니다.

운영자 인터뷰에 입력한 답변과 생성된 소개·FAQ 초안은 요청 처리 중에만 사용하며 공용 검사 캐시나 회원 검사 이력에 저장하지 않습니다. AI 기억 검사에 입력한 소비자 질문은 Gemini 답변 생성을 위해 Google에 전달됩니다. 질문에는 개인정보나 공개하지 않은 사업 정보를 입력하지 마세요.

## 4. 소셜 로그인

Google·카카오·네이버 로그인을 선택하면 해당 사업자의 동의 화면에서 허용한 계정 식별 정보와 프로필 정보를 받습니다. 제공 범위는 각 사업자의 동의 화면에서 확인할 수 있으며, Gmail 메일함이나 메일 내용에 접근하는 권한은 요청하지 않습니다. 소셜 로그인으로 받은 계정 토큰은 서버에서 암호화해 저장합니다.

## 5. 동의 거부 권리와 불이익

사용자는 필수 개인정보 수집·이용에 동의하지 않을 권리가 있습니다. 동의를 거부하면 이메일 회원가입과 회원 전용 사이트 저장·검사 이력 기능을 이용할 수 없습니다. 로그인 없이 제공되는 공개 예시와 운영자가 허용한 제한적 체험 기능은 별도로 이용할 수 있습니다.

가입 버튼을 누르기 전에 화면의 `[필수] 개인정보 수집·이용 동의` 항목을 직접 선택해야 합니다. 선택하지 않으면 가입 요청을 제출할 수 없습니다.

## 6. 삭제와 정정

내 사이트와 개별 검사 이력은 로그인한 화면에서 직접 삭제할 수 있습니다. 회원 탈퇴도 계정 화면에서 직접 처리할 수 있습니다. 공개 문의 글에는 이메일, 비밀번호, 인증번호나 로그인 토큰을 적지 마세요.
